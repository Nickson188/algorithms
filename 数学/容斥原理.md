```cpp
情况一：求“至少满足一个条件”（集合的并集） 奇加偶减
|A集合 并 B集合 并 C集合| = (|A集合|+|B集合|+|C集合|)-(|A集合 交 B集合|+|A集合 交 C集合|+|B集合 交 C集合|)+|A集合 交 B集合 交 C集合|
1 个条件（奇数）：加
2 个条件（偶数）：减
3 个条件（奇数）：加

情况二：求“所有条件都不满足”（全集减去违规项） 奇减偶加
合法方案 = |U全集| - |A集合 并 B集合 并 C集合| = |U全集|-(奇数项-偶数项) = |U全集|-奇数项+偶数项
0 个限制（偶数）：全集，正号
1 个限制（奇数）：减号
2 个限制（偶数）：加号
3 个限制（奇数）：减号
```
